# [Step 0] KIS 종목/시장 리서치 (You.com)

## Purpose

전략을 설계하거나 주문을 내리기 전에, You.com Search/Research API로 종목·업종·시장에 대한
최신 웹 정보(뉴스, 동향, 실적 맥락 등)를 조사한다. 조사 결과는 전략 설계(Step 1)나
신호 판단(Step 3)의 참고 자료로만 사용하며, 그 자체로 매매를 실행하지 않는다.

## Prerequisites

- 환경변수 `YDC_API_KEY` 설정 필요.
  [https://you.com/platform/api-keys](https://you.com/platform/api-keys) 에서 발급
  (신규 가입 시 무료 크레딧 제공).
- KIS 인증은 필요 없음 (You.com API만 사용하는 조회 전용 기능).

## 스크립트 경로

프로젝트 루트의 `{{AGENT_DIR}}/scripts/` 에 있다. 실행 시 **절대 경로**를 사용한다.
먼저 `pwd`로 현재 디렉토리를 확인하고, 프로젝트 루트를 기준으로 경로를 구성한다.

- 웹 검색: `uv run <프로젝트루트>/{{AGENT_DIR}}/scripts/youcom_research.py search "<검색어>" [--count N]`
- 심층 리서치: `uv run <프로젝트루트>/{{AGENT_DIR}}/scripts/youcom_research.py research "<검색어>"`

## 인자 처리

`$ARGUMENTS`(사용자 요청)를 바탕으로 검색어를 구성하고, 요청 성격에 따라 동작을 선택한다.

| 요청 예시 | 동작 | 서브커맨드 |
|---|---|---|
| "삼성전자 최근 뉴스 조사해줘" | 최신 뉴스/웹 결과 다건 확인 | `search` |
| "SK하이닉스 요즘 어때?" | 빠른 웹 검색 | `search` |
| "반도체 업종 동향 요약해줘" | 여러 출처를 종합한 심층 리서치 | `research` |
| "이 종목 실적 배경 자세히 알아봐줘" | 심층 리서치 | `research` |

## 실행 순서

### 1. 검색어 구성

사용자 요청에서 종목명/종목코드/주제를 추출해 자연스러운 한국어 검색어로 구성한다.
(예: "삼성전자 관련 뉴스 조사해줘" → 검색어 `"삼성전자 최근 뉴스"`)

### 2. 스크립트 실행

- 빠르게 여러 건을 훑어야 하면 `search` (기본 10건, 최대 20건, `--count`로 조정)
- 배경/맥락을 종합 요약해야 하면 `research`

### 3. 결과 정리 후 사용자에게 전달

스크립트가 출력한 한국어 텍스트(제목·URL·요약 또는 리서치 요약·출처 목록)를 그대로 붙여넣지 않고,
질문 의도에 맞게 핵심만 요약해서 전달한다. 근거가 필요한 경우 출처 URL을 함께 표시한다.

### 4. 다음 단계 제안

리서치 결과를 바탕으로 전략 설계나 백테스트가 필요하면 다음 단계를 안내한다.

## 안전 규칙

- **조회 전용**: 이 스킬은 어떤 경우에도 주문을 실행하거나 KIS 계좌에 접근하지 않는다.
- **API 키 비노출**: `YDC_API_KEY` 값은 어떤 경우에도 화면에 출력하거나 로그에 남기지 않는다.
  스크립트가 반환한 결과 텍스트만 참조한다.
- **키 미설정 시**: 스크립트가 안내하는 오류 메시지를 그대로 전달하고,
  `https://you.com/platform/api-keys` 에서 발급 후 환경변수로 설정하라고 안내한다.
- 리서치 결과는 참고용 정보이며, 투자 조언이나 확정적 사실로 단정하지 않는다.

## Troubleshooting

- **`YDC_API_KEY` 미설정 오류** → 키 발급 후 환경변수 설정 안내, 재시도
- **검색 결과 없음** → 검색어를 더 구체적으로(종목명+키워드) 조정해 재시도
- **요청 한도 초과(429)** → 잠시 후 재시도 안내
- **네트워크/타임아웃 오류** → 연결 상태 확인 후 재시도
